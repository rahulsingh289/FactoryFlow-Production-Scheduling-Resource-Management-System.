🚀 Production Scheduler - Quick Start

Operating Systems Project - CPU Scheduling Algorithms

⚡ Quick Start for Windows Users:
Just double-click run.bat file in the project folder!

Step 1: Check Requirements

Make sure you have installed:

  • Node.js - Download here
  • C++ Compiler (g++ or MinGW) - Download MinGW

Open Command Prompt and verify:

node --version
npm --version
g++ --version

Step 2: Run the Application

Windows (Easiest):

Double-click run.bat in the project folder

Windows (Command Prompt):

cd path\to\Smart_Factory_Production_Scheduler_50pct
run.bat

Windows (PowerShell):

cd path\to\Smart_Factory_Production_Scheduler_50pct
.\run.ps1

macOS/Linux:

cd path/to/Smart_Factory_Production_Scheduler_50pct
./run.sh

Step 3: Access the Dashboard

The browser should open automatically. If not, manually open:

Open Dashboard (http://localhost:3000)

📚 Features

  • 3 Scheduling Algorithms: FCFS, SJF, Priority
  • Add Custom Orders: Click "Add Order" button
  • Visual Timeline: See order scheduling in real-time
  • Statistics: Average wait time, late orders tracking
🛠️ Troubleshooting:
If something doesn't work, check WINDOWS_SETUP.md or README.md for detailed instructions!
